# 拾藏 AI

> 把散落在抖音、小红书里的有用内容，变成可以再次找到的个人知识收藏。

[在线体验](https://shicang-d5ghnihwq293cd52c-1490550935.tcloudbaseapp.com/) · 手机优先 · PWA 可安装 · 零付费 AI API

## 项目背景

短视频和图文平台的收藏越来越多，但真正需要时往往找不到。拾藏 AI 解决的是“收藏之后如何重新发现”的问题：用户复制抖音或小红书分享内容，应用保存原文和链接，通过本地规则完成分类、搜索、回顾与统计。

项目在 MVP 阶段有意不接入付费 LLM、语音转写、视觉识别或 Embedding API，优先验证核心使用闭环，并控制个人项目的长期运行成本。

## 核心功能

- 支持抖音、小红书分享文字及短链接导入。
- 一键读取手机剪贴板，收藏成功后自动清空输入框。
- 重复链接检测，避免连续点击产生重复收藏。
- 根据标题、分享文案及话题标签进行可解释的规则分类。
- 首次使用时由用户选择感兴趣的分类，也可以创建、删除和改名。
- 用户手动修改过的分类和标签不会被自动规则覆盖。
- “今日回顾”优先展示保存较久且较少回顾的内容，而不是纯随机。
- “寻藏”支持自然语言风格关键词搜索、分类和标签匹配。
- 本周收藏数量、分类分布和标签统计均来自真实数据。
- 支持 PWA 安装，可添加到手机桌面。
- 所有收藏数据默认保存在用户自己的浏览器中，不上传图片或个人收藏数据。

## 产品演示

线上地址：<https://shicang-d5ghnihwq293cd52c-1490550935.tcloudbaseapp.com/>

腾讯云默认测试域名第一次访问会显示安全提醒，等待倒计时后点击“确定访问”即可。正式产品可绑定已备案的自定义域名移除该页面。

推荐体验流程：

1. 首次打开并选择感兴趣的分类。
2. 在抖音或小红书点击“复制链接”。
3. 回到拾藏，点击“从剪贴板读取并收藏”。
4. 在“我的”查看分类结果，在“寻藏”中搜索，在“今日回顾”中重新发现。

## 技术设计

### 在线 PWA

- 原生 HTML、CSS、JavaScript，无前端框架运行时依赖。
- LocalStorage 持久化收藏和用户分类，不采集个人账号数据。
- Service Worker 提供应用外壳缓存和桌面安装能力。
- 腾讯云 CloudBase 静态托管，面向中国大陆手机网络访问。

### 本地参考后端

- Node.js HTTP 服务。
- SQLite 数据持久化。
- 数据模型预留 `user_id`、`ai_summary`、`transcript`、`knowledge_items`、`embedding` 等未来扩展字段。
- 分类器、搜索词处理和回顾评分位于独立核心模块，未来可替换为 AI 服务。

## 关键产品决策

1. **解析失败也必须保存**：分享文案、原链接和导入时间是最低可靠数据，不因平台页面不可访问而丢失收藏。
2. **不使用无水印解析接口**：不依赖绕过平台限制、易失效或合规风险较高的第三方服务。
3. **规则优先于付费 AI**：关键词分类虽然简单，但成本为零、结果可解释，并保留了替换为 LLM classifier 的服务边界。
4. **回顾不是随机抽卡**：根据收藏时间、最近回顾时间和回顾次数计算优先级。
5. **隐私优先**：当前线上版把数据保存在用户设备中，图片不上传服务器。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm start
```

Windows 用户也可以双击项目根目录的 `启动拾藏AI.cmd`，然后访问 `http://127.0.0.1:4173`。本地 Node 版数据保存在 `data/shicang.db`。

## 当前限制

- 抖音和小红书没有向普通第三方应用开放个人收藏列表读取接口，因此不能批量抓取账号历史收藏。
- 当前线上版没有账号和跨设备同步；清除浏览器数据会删除该设备上的收藏。
- OCR 依赖浏览器本地能力，不支持时需要手动输入图片文字。
- 纯图片、视频语音和画面暂不进行深度理解。

## 后续规划

- 手机号或微信登录及跨设备同步。
- 免费或自托管 OCR 服务。
- 可选的 AI 分类、摘要和知识提取。
- Embedding 语义搜索与 RAG，同时保留全文搜索作为后备。
- 完整的 Android / HarmonyOS 分享入口。
